# SMS parsing

Laya was disabled in v0.45.30 at the user's request. SMS transaction recognition
again uses the local bank-independent posting grammar. No message is sent for
model decisions. See [local SMS imports](sms-local-import.md).

The historical v0.45.27-v0.45.29 implementation remains in Git history. Do not
re-enable the old service unless the user explicitly requests it.
